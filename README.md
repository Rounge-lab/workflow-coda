## About workflow-coda

**workflow-coda** turns files generated by any pipeline into a single,
self-contained HTML report that opens offline in a browser.

Verify your output files with `workflow-coda verify`, describe them in a
manifest, and select built-in or plugin components to present them. A layout
declares how those components are arranged; `workflow-coda build` assembles
the report, explicitly reporting provenance information.

## Installation

> [!NOTE]
> Requires **Python 3.14 or later**.

### Latest release

Install directly from the latest GitHub release:

1. Download the wheel (`.whl`) from the [latest release](https://github.com/Rounge-lab/workflow-coda/releases/latest).
2. Install the downloaded file:

```bash
python -m pip install /path/to/workflow_coda-<version>-py3-none-any.whl
```

### From the repository

```bash
git clone https://github.com/Rounge-lab/workflow-coda.git
cd workflow-coda
python -m pip install .
```

### Development and local documentation

Install [Pixi](https://pixi.sh), then run from the repository root:

```bash
pixi install
pixi run test
```

The development environment installs workflow-coda in editable mode.
To build the documentation locally:

```bash
pixi run docs
```

Open `docs/build/html/index.html` in your browser.

## Quick start

1. **Verify files** with `workflow-coda verify` to check artifact contracts.
2. **Write a manifest** describing the run's artifacts and their locations.
3. **Choose components** for metrics, tables, charts, prose, or notices.
4. **Declare a layout** arranging and configuring those components.
5. **Build the report** with `workflow-coda build`.

See the [first-report tutorial](https://workflow-coda.readthedocs.io/en/latest/user/tutorials/hello-report.html)
for commands and complete examples.
