=========
Reference
=========

The reference documentation describes the shipped software as it is,
in two sections: the **framework reference** — the framework's own
interfaces (the Python API, the command line interface, the YAML
schemas) — and the **core plugins reference** — the placement
grammar of the components workflow-coda ships with itself.  Every
page is written against its source of truth: the API pages are
generated from the code through autodoc, and the schema and plugin
pages are written against the models and the components' declared
grammar.
