=========
Reference
=========

The reference documentation describes the shipped software as it is:
the framework's Python API, the command line interface, the YAML
schemas, and the core plugins that ship with workflow-coda itself.
API pages are generated from the code through autodoc; the schema and
plugin pages are written against the models and the components'
declared grammar, each close to its source of truth.
