=============================
Core components and verifiers
=============================

``workflow-coda`` ships with a set of generally useful, field-agnostic
components and verifiers; the ``core`` plugins. Everything included in the
``core`` plugins should get you started quickly building reports.  Every
component page follows the same shape, he component’s identity, how to place it,
its parameter grammar (a closed vocabulary), its semantics (variants, colors,
policies), and its outcomes and page chrome. The :doc:`core-plugins` pages
outline what is included in the ``core`` plugins.
