=============
Workflow Coda
=============

A plugin-based composable static HTML report generator for integration with
pipeline workflows.

Development
-----------

.. code-block:: console
   :caption: Development setup

   pixi install

.. code-block::
   :caption: Generate documentation

   pixi run docs

Checks
^^^^^^

.. code-block:: console
   :caption: Commit checks

   pixi run lint

.. code-block:: console
   :caption: Pull-request checks

   pixi run test
